# ВОнтакте

Независимая социальная сеть для Android.

## Уже в проекте
- 🔐 Вход и регистрация по номеру телефона через Firebase Auth
- 📰 Лента, публикация текста и фото/видео
- ❤️ Лайки и 💬 комментарии
- 👥 Друзья и сообщения
- 👥 Группы и 📢 каналы с участниками и ролями
- 🤖 Создание ботов, команды и каталог ботов
- 🔔 Firebase Cloud Messaging для уведомлений
- 📞 система звонков
- 🛡️ серверная модерация контента
- 🎨 фирменный интерфейс ВОнтакте и иконка «ВО»

## Firebase
Android-пакет: `com.montakte.app`  
Firebase-проект: `bontakte`

`google-services.json` должен соответствовать этому Android-пакету.

## Сборка
GitHub Actions автоматически собирает debug APK после изменений в `main`.
Артефакт сборки называется `VOntakte-debug-apk`.

## Важно
Серверные Firebase Functions требуют отдельного деплоя в Firebase; наличие исходников в репозитории само по себе не означает, что Functions уже опубликованы.
